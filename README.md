# 💼 Personal Portfolio

A modern, responsive, and interactive developer portfolio built with **Next.js**, **React**, **Tailwind CSS**, and **Framer Motion**. This portfolio showcases my projects, technical skills, education, and contact information with a clean and user-friendly design.

## 🌐 Live Demo

> https://your-portfolio-url.vercel.app

---

## ✨ Features

- 🎨 Modern and responsive UI
- ⚡ Built with Next.js App Router
- 📱 Mobile-first design
- 🎭 Smooth animations with Framer Motion
- 💼 Project showcase
- 🛠 Skills section
- 🎓 Education timeline
- 📧 Contact section
- 🌙 Beautiful dark theme
- 🔝 Smooth scroll navigation
- 🚀 Optimized for performance and SEO

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Masud76301/my-portfolio.git
```

### Navigate to the project

```bash
cd my-portfolio
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:3000
```
