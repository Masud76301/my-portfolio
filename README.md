# 💼 Personal Portfolio

A modern, responsive, and interactive developer portfolio built with **Next.js**, **React**, **Tailwind CSS**, and **Framer Motion**. This portfolio showcases my projects, technical skills, education, and contact information with a clean and user-friendly design.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/portfolio.git
```

### Navigate to the project

```bash
cd portfolio
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:3000
```
